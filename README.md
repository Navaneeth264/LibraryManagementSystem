# 📚 Library Management System

A simple Library Management System built using Flask, Python, SQLite, HTML and CSS.

## 🚀 Features

- Add books
- View books
- Delete books
- Store book information using SQLite
- Simple and responsive user interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
