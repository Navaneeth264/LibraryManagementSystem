# 📚 Library Management System

A simple and user-friendly Library Management System developed using **Python, Flask, SQLite, HTML, CSS, and JavaScript**.

The system allows users to securely log in and manage library books. Users can add, update, search, issue, return, and delete books through a web-based interface.

---

## 🚀 Features

- 🔐 User Login and Logout
- ➕ Add New Books
- ✏️ Update Book Details
- 🔍 Search Books
- 📕 Issue Books
- 📗 Return Books
- 🗑️ Delete Books
- 🟢 Available / 🔴 Issued Book Status
- ✅ Form Validation using JavaScript
- 👁️ Show / Hide Password
- ⚠️ Confirmation dialogs for Issue, Return, and Delete
- 📱 Responsive user interface
